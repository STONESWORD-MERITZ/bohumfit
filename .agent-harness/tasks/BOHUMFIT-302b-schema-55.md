## ★설계 판정 — "55행"과 "회색 3행"이 정확히 정합한다
- **신설 3행**: `thrombolysis_cerebral`·`thrombolysis_cardiac`·`cancer_integrated_limit` → 52 + 3 = **55** ✓
- **회색(`sum_excluded`) 3행**: `cancer_integrated_limit`(신설) + `circulatory_treatment`(기존·이동) +
  `disability_80`(기존 80% 후유장해) = **3** ✓
- ★`순환계 치료비`는 **신설이 아니라 위치·성격 변경**(심장 말미 → 뇌 최상단 · sum_excluded 부여)이라
  +3에 포함되지 않는다. 두 숫자가 모순이 아니었다.

### 5-1. 정본 4문서 — ★두 지표를 분리해 센다
회색 행이 생기면 "총액"의 의미가 갈린다. 한 지표만 보면 오판하므로 **둘 다** 낸다.
- **①값 보존** = enrolled 전체 합(**회색 포함**) — 값이 이동만 했다면 **불변**이어야 한다.
- **②표시 합계** = `sum_excluded` 제외(대분류 합계와 같은 규칙) — 회색화한 만큼 줄어드는 게 정상이다.

| 문서 | rows(전→후) | ① 값보존(전→후) | Δ① | ② 표시합계(전→후) | Δ② |
|---|---|---|---|---|---|
| 정본A | 59→**62** | 614,860,000→614,860,000 | **0** | 594,860,000→594,860,000 | **0** |
| 정본B | 58→**61** | 1,467,790,000→1,467,790,000 | **0** | 1,465,790,000→**1,464,290,000** | **−1,500,000** |
| 정본C | 55→**58** | 398,960,000→398,960,000 | **0** | 398,960,000→398,960,000 | **0** |
| 정본D | 57→**60** | 476,440,000→476,440,000 | **0** | 466,440,000→466,440,000 | **0** |

★**Δ① = 4문서 전부 0** → 신규 회색 행이 값을 만들어내지 않았고 손실도 없다(패킷의 "총액 불변" 요구 충족).
★**Δ②는 정본B만 −1,500,000** → 사유: `순환계 치료비` 1,500,000이 **회색화(sum_excluded)** 되어 표시 합계에서
  빠졌다. 대분류로는 **심 장 41,500,000 → 40,000,000**(같은 −1,500,000). A·C·D는 순환계 치료비 값이 없어 0.
  → **모든 Δ가 사유에 귀속된다. 사유 없는 변화 0.**
(rows +3 = 스키마 52→55. 정본별 비고행 수는 불변.)

### 5-2. 통합치료비 보유 제안서 **8건 전수**(추정 0)
| 케이스 | 담보수(전→후) | 신규 착지 | 폐기 |
|---|---|---|---|
| 순환계 有 6건 | +1 | 암 통합치료비 한도 130,000,000 · 뇌/심장 혈전용해 **각 1,000만**(4건) 또는 **각 700만**(3건 — 순환계 3,000만 설계) | 구 비고 한도 라벨 2건 → 0 |
| 순환계 無 2건 | **−1** | 암 통합치료비 한도 130,000,000 | 구 비고 한도 라벨 2건 → 0 |
★담보수 증감은 전부 설명된다: (혈전용해 +2) + (한도 행 +1) − (구 비고 라벨 −2) = **+1**(순환계 有) /
  (한도 +1) − (구 비고 −2) = **−1**(순환계 無).
★혈전용해 금액이 케이스별로 다르다(1,000만 vs 700만) — 요율표의 순환계 가입금액(5,000만 vs 3,000만) 차이와 정합.
