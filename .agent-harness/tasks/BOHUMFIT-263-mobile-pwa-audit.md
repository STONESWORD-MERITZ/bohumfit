| 요건 | 현황 | 근거 |
| --- | --- | --- |
| **manifest** | ✅ 존재·등록됨 | `public/site.webmanifest`, `index.html:10` |

| **오프라인 대응** | ❌ **미구현** | `caches.`·`navigator.onLine` **0건** |
| **설치 프롬프트 제어** | ❌ 미구현 | `beforeinstallprompt` **0건** |
| 앱 모드 감지 | ❌ 없음 | `display-mode`/`standalone` 참조 0건 |
| 안전영역 대응 | ❌ 없음 | `env(safe-area-*)` 0건 |

**정리**: manifest·아이콘·메타라는 **설치 메타데이터는 존재**한다. 다만 실제 브라우저의
설치 제공 여부를 이번 자동화가 판정하지는 않았고, 앱이 직접 제어하는 설치 프롬프트도 없다.
**서비스 워커가 없어 오프라인·캐시·업데이트 제어는 전무**하므로 실질 PWA 기능은 미구현이다.

**브랜드 가이드 대비(이미지 실측)**:
- `icon-192.png`: **흰 타일 + 에메랄드 ㅍ** — 앱 아이콘 규격과 일치.
- `favicon-32.png`: **에메랄드 타일 + 흰 ㅍ** — 파비콘 규격과 일치.
- 512·180·16px 자산도 선언 규격과 실제 픽셀 크기가 일치한다. 시안 단계의 아이콘 재확인은
  필수가 아니라 **현행 자산 유지 요건**이다.
