## 2. 현행 40행 → 목표 42행 매핑표

### 유지 (이름만 정렬) — 21행
`상해수술`→상해수술비 · `질병수술`→질병수술비 · `뇌혈관수술`→뇌혈관수술비 ·
`심혈관수술`→심장질환수술비 · `암진단금`→암진단비(일반암) · `유사암진단금`→유사암진단비 ·
`암수술`→암수술/로봇암수술 · `뇌혈관질환`·`뇌졸중`·`뇌출혈` · `심혈관질환`→심장질환 ·
`허혈성심장질환`·`급성심근경색` · `상해입원`·`질병입원` · `상해사망`·`질병사망` ·

## 5. 구현 분할 제안

한 태스크로 하기엔 크다. **4단계**로 나눈다.

| 단계 | 범위 | 산출 | 게이트 |
|---|---|---|---|
| **S1** 스키마 정의 | `constants.py` 42행·`GROUP12` 재정의 + 별칭 확장. **export는 손대지 않는다** | 새 상수 + 매핑 단위 테스트 | 기존 테스트는 깨진다 → S1에서 **기대값 갱신 범위를 확정**하고 Human 승인 |
| **S2** 집계 배선 | `aggregator.py` 롤업·`yn_flags` 재배선 | 그룹 롤업 테스트 | 정본 2건 **집계 결과** 대조표(값 변화 전수 기록) |
| **S3** 산출물 | `export_excel.py`·`export_pdf.py` 행 순서·2열 병기·비고행 | 프로토타입(286 Phase C)과 **동일 모양** | ★smoke 기준값 갱신 + Human 눈 승인(Q6) |
| **S4** 3층 커버리지 | 신설 행 대응 매칭 규칙(중입자·상해입원일당·골절수술비 등) | 원문 근거별 테스트 | 각 규칙마다 원문 페이지 근거 병기 |
