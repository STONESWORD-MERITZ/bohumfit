## ② 후유장해 "80%이상" 처리 (Human 결정 반영)

### S0 — 진단 (★태스크 가정과 다름 — 오분류는 없었음)
- 현행 분류는 **이미 3-100%와 80%이상을 분리**하고 있었다(236 F 담보명 기반 패턴 → 별도 라벨 `80%이상 후유장해`).
- E 케이스 산술 검증: overview `상해80%미만후유장해 5,100만`의 구성은 **3-100% 담보 2건**
  (`상해후유장해(3-100%)` 5,000만 + `재해후유장해(3~100%)` 100만 = 5,100만)이고,
  80%이상 담보 2건(`갱신형 일반상해80%이상` 100만 + `보통약관(상해80%이상)` 100만 = 200만)은
  **이미 별도 행**으로 잡혀 있었다 → "80%미만 버킷에 포함" 가설은 **재현되지 않음**.
- C 케이스도 동일: KB 질병80%미만 4,000만 = 질병후유장해 1,000만 + 질병50%이상 3,000만(검산 일치),
  80%이상(7,000만)은 별도.
- 참고(설계 근거): 담보명 기반 판정은 KB가 **한 담보를 여러 지급사유로 중복 표기**하는 경우
  (A: `일반상해후유장해`가 `상해후유장해`/`상해80%이상후유장해` 두 줄) 중복 계상을 방지한다 — 분류 기준 무변경.

### S1 — 수정 (2026-07-24 Human 결정 · 244 양식 기준 정합)
- 결정: **"80%이상" 후유장해를 후유장해 대분류 집계에서 제외(미포섭)**. 상해/질병 후유장해 집계는 **3-100% 담보만**.
- 구현: `EXTRA_LABEL_GROUP`에서 `"80%이상 후유장해": "후유장해"` 매핑 **제거** → 기본값 기타(GROUP_ETC)로 표시.
  **담보 자체는 기타에 남아 정보 손실 0**, 대분류 체계(13분류) 변경 0, 분류 규칙(classify_extra) 변경 0.
