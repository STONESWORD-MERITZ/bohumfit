### F-7 — PDF 폭탄(파싱 중 자원 폭증) 방어 없음
- 위치: `backend/pipeline/pdf_parser.py` 경로 전반
- 위험: 크기 상한은 있으나, **작은 파일이 파싱 중 메모리·CPU를 폭증**시키는 케이스는 막지 못한다.
  순차 파싱이 피크를 1파일분으로 묶는 것이 유일한 완화다.
- 심각도: **오픈 후 처리**(오픈 직후 트래픽이 낮다면 감내 가능)
- 재현 조건: ★**확인 불가** — 악성 PDF 표본을 만들지 않았다(생성 자체가 범위 밖).
- 수정 방향: 페이지 수 상한 + 파싱 단위 타임아웃(파일별) 추가.

# 확인 불가 목록 (사유)

1. **좌표 히트 테스트** — 브라우저 pane `clientWidth`가 0으로 보고돼 `elementFromPoint`가 `null`.
   기하학적 겹침 0으로만 판정했다. 실기기 필요.
2. **실계정 2개 E2E** — `VITE_SUPABASE_URL`·`ANON_KEY` 부재로 로그인 동선 실행 불가.
   저장소 계약은 실브라우저 모듈 호출로 검증했다(277 2차).
3. **운영 DB 기존 저장분** — 접근하지 않았다(조회가 곧 PII 열람).
4. **운영 Sentry 실제 이벤트·Railway 로그 보존** — 접근 권한 밖.
5. **F-5 재현** — 가입제안서 표본이 **1건뿐**이라 담보 중복 등장 케이스를 만들 수 없다.
6. **F-7 재현** — 악성 PDF 표본을 만들지 않았다(범위 밖).
7. **실제 설치 이벤트·waiting worker·iOS safe-area 34px** — 합성 조건으로만 재현.
